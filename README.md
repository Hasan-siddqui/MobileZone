# MobileZone - Premium Smartphones
MobileZone is a modern e-commerce website offering the latest smartphones and accessories. Built with HTML, CSS, and JavaScript, it features advanced SEO, responsive design, and dynamic functionality.

## Features
- Product catalog with filtering and sorting
- Add-to-cart and wishlist functionality
- Mobile-friendly design
- SEO-optimized for search engines
